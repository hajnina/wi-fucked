# Dependency-ordered (deps first) kernel module list for the QEMU proof.
# Computed from Alpine v3.19 x86_64 lts modloop's modules.dep by walking the
# transitive closure of: wireguard.ko, sch_cake.ko, nft_masq.ko,
# nft_chain_nat.ko, 8021q.ko. Regenerate if module_closure.txt's seeds
# change or a new Alpine release changes dependency names.
